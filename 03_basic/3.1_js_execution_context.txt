++++++++++++++++++++++++++++++++++++++++++++++++++++++++ CALL STACK +++++++++++++++++++++++++++++++++++++++++++++++++++++++++

Definition :- The call stack in JavaScript is a data structure that keeps track of which functions are currently being executed. It follows the LIFO (Last In, First Out) principle—the last function added to the stack is the first one to finish and be removed.


EXAMPLE:-


function one() {                                          
                                                
  two();
}

function two() {
  three();
}

function three() {
  console.log("Inside three");
}

one();
